# 🏢 موقع وظائف شركة الرافدين — نظام الرتب والسجلات

موقع وظائف ثابت (HTML/CSS/JS بدون سيرفر) يعرض الوظائف الشاغرة مرتّبة حسب **الرتبة الوظيفية**،
ويستقبل طلبات التقديم ويحفظها في **سجلات** يتابعها المسؤول من لوحة خاصة.

---

## 📁 هيكل المشروع

```
Jobsite2/
├── index.html                  # الصفحة الوحيدة (الهيكل + الروابط)
├── assets/
│   ├── css/
│   │   └── style.css           # كل التنسيقات (RTL، متغيرات الألوان، الجوال)
│   └── js/
│       ├── config.js           # ⚙️ الإعدادات: اسم الشركة، التواصل، رمز الدخول، الرتب والحالات
│       ├── utils.js            # 🧰 أدوات: ترميز HTML، توست، تواريخ، تحقق من الهاتف/البريد، CSV
│       ├── seed.js             # 🌱 البيانات الابتدائية (الوظائف + السجلات التجريبية)
│       ├── store.js            # 💾 طبقة البيانات: قراءة/كتابة/تطبيع/إحصاءات/تصدير
│       ├── views/
│       │   ├── jobs.js         # 📋 قائمة الوظائف + التفاصيل + نموذج التقديم
│       │   └── records.js      # 🗂️ بوابة الرمز + لوحة السجلات (فلترة/حالة/حذف/تصدير)
│       └── app.js              # 🧭 الموجّه (Router) + الإحصاءات + نقطة التشغيل
├── tests/
│   └── smoke.test.mjs          # ✅ اختبار تلقائي يجرب النظام كامل
├── package.json                # أوامر التشغيل والاختبار
└── README.md
```

**ترتيب تحميل السكربتات مهم:** `config → utils → seed → store → views → app`

---

## ▶️ التشغيل

الأسهل: افتح `index.html` مباشرة بالنقر المزدوج (يعمل بدون إنترنت).

أو عبر سيرفر محلي (أفضل، لأن بعض المتصفحات تقيّد `file://`):

```bash
npm start          # أو: python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

## 🧪 الاختبار

```bash
npm install        # يثبّت jsdom (مكتبة تطوير فقط)
npm test           # يشغّل 23 فحص على النظام كامل
```

## ✨ مميزات النظام

| الجزء | التفاصيل |
|---|---|
| **الرتب الوظيفية** | 5 رتب (إدارة عليا → مبتدئ)، لكل رتبة لون وشارة خاصة، والقائمة مرتّبة تلقائياً من الأعلى رتبة |
| **البحث والفلترة** | بحث في العنوان/القسم/المكان/نوع الدوام + فلترة بالرتبة |
| **التقديم** | نموذج تحقّق (اسم، هاتف عراقي، بريد) مع منع التكرار بنفس الرقم على نفس الوظيفة |
| **آخر موعد** | يحسب الأيام المتبقية ويُغلق التقديم تلقائياً بعد انتهاء الموعد |
| **السجلات** | لوحة محمية برمز: إحصاءات، فلترة (رتبة/حالة/بحث)، تغيير الحالة، حذف، تصدير CSV |
| **الحفظ** | `localStorage` — البيانات تبقى بعد إغلاق المتصفح، مع استعادة تلقائية عند تلف البيانات |
| **الروابط** | مسارات قابلة للمشاركة: `#/jobs` · `#/job/3` · `#/records` |

## ⚙️ التخصيص السريع

1. **بيانات الشركة والتواصل:** `assets/js/config.js`
2. **رمز دخول السجلات:** `CONFIG.accessPin` في نفس الملف (التجريبي: `1234`)
3. **الوظائف والسجلات الابتدائية:** `assets/js/seed.js`
4. **الألوان والخطوط:** متغيرات `:root` في `assets/css/style.css`

> ⚠️ بعد أول تشغيل تُحفظ نسخة في متصفحك، فتعديل `seed.js` لا يظهر إلا بالضغط على
> زر **«↺ استعادة البيانات»** في لوحة السجلات (أو بحذف بيانات الموقع من المتصفح).

## 🔐 ملاحظة أمنية مهمة

رمز الدخول الحالي **موجود داخل كود الصفحة**، أي أن أي شخص يفتح أدوات المطوّر يقدر يشوفه.
هذا مناسب للعرض التجريبي فقط. للاستخدام الحقيقي لازم:

1. سيرفر (Backend) يستقبل الطلبات ويحفظها في قاعدة بيانات.
2. تسجيل دخول بكلمة مرور مشفّرة (مثل bcrypt) + جلسة (Session/JWT).
3. التحقق من المدخلات على السيرفر أيضاً (تحقق المتصفح وحده لا يكفي).
4. حفظ بيانات المتقدمين في قاعدة بيانات، لا في متصفح الزائر.

## 🧾 سجل التحويل من الملف القديم

النسخة السابقة كانت ملف HTML واحد باسم `موقع-وظائف-بالرتب-والسجلات (2).html`.
تم تحويلها إلى المشروع المنظّم أعلاه مع الإصلاحات التالية:

- ✅ فصل CSS و JS عن HTML وتقسيمها إلى وحدات (config / utils / seed / store / views / app)
- ✅ إزالة سكربتات التتبع الخارجية (Cloudflare Beacon و email-decode) والبريد المشفّر
- ✅ معالجة ثغرات **XSS**: ترميز كل مدخلات المستخدم قبل إدراجها في HTML
- ✅ إصلاح انهيار الصفحة عند تعطيل `localStorage` (الوضع الخاص) — صار يعمل بلا حفظ
- ✅ التعافي التلقائي من بيانات تالفة بدل شاشة بيضاء
- ✅ منع التقديم المكرر + تحقق من رقم الهاتف والبريد
- ✅ إغلاق التقديم تلقائياً بعد آخر موعد + عدّاد الأيام المتبقية
- ✅ مسارات (Router) بالـ hash تدعم زر الرجوع والروابط المباشرة
- ✅ تحسينات وصولية: `label` مخفية، تنقل بلوحة المفاتيح، `aria-live` للرسائل
- ✅ تصدير CSV آمن (يهرب الفواصل وعلامات التنصيص) + عمود الملاحظات
- ✅ زر «قفل» للوحة السجلات + زر استعادة البيانات الابتدائية
- ✅ إضافة اختبار تلقائي (23 فحص) يغطّي كل المسارات
